# Contributing to DevFlow

Thank you for your interest in contributing.

## Before opening a pull request
- Search existing issues and pull requests for related work.
- Open an issue before making a large or breaking change.
- Keep each pull request focused.

## Development setup
```bash
python -m pip install -e ".[dev]"
```

## Checks
```bash
pytest
ruff check .
```

## Pull request checklist
- Explain the problem and proposed change.
- Add or update tests for behavior changes.
- Update documentation when behavior changes.
- Keep changes compatible with supported Python versions.

Please be respectful and constructive in project discussions.
